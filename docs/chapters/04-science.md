# 四 科学与自然

读科普不是为了记住"光速 30 万公里每秒"或者"线粒体是细胞的能量工厂"这种事实。事实可以查，记住也很容易忘。

读科普真正的收获是科学方法。一个观点怎么被提出、怎么被检验、怎么被一群人反复砸出问题、然后被一个更好的观点替代 - 这套流程是一种思维训练。看完达尔文怎么用三十年攒证据，再看自媒体上那种"震惊体"，你会本能地问：他的样本是什么？反例处理了吗？这个解释是不是顺手编的？

科学的另一面是它逼你接受"我们其实不知道"。量子力学到现在没人真的"懂"它，物种起源出来一百多年生命的起源还是开放问题。能跟未解之谜共处、不急着给一个糟糕的答案，这件事生活里也用得上。

这一章选了 10 本，物理、生物、进化、生态、化学都有。先从布莱森和罗韦利这种讲得轻松的入门，再进道金斯、薛定谔这种逻辑硬一点的，最后留两本环境主题让你看科学怎么变成行动。

## 《万物简史》

布莱森 / 2003 / 入门

一本写给"上学时被理科课劝退的人"的科学史。

布莱森是旅行作家，不是科学家，他的优势恰好在这里：他会记住一个普通读者第一次听说"原子核小到像大教堂里一只苍蝇"时的震惊，然后用这种震惊去讲整个宇宙、地球、生命的故事。书里花了很大篇幅写科学家本人 - 卡文迪什测地球密度时怕人怕到只用纸条交流，孟德尔种豌豆的论文被埋没三十多年。读完会发现科学不是教科书里那种从公理到定理的干净东西，是一群古怪的人在错误里摸出来的。适合想重新对世界感到好奇的成年人。

配套：想再深一点可以读《七堂极简物理课》。

## 《七堂极简物理课》

罗韦利 / 2014 / 入门

意大利物理学家用 100 页讲完二十世纪物理学的全部精华。

这本书短到一个下午能读完，但密度极高。罗韦利讲广义相对论时说："爱因斯坦发现，引力场和空间不是两个东西，它们是同一个东西。"一句话把一个一般要花一学期讲的概念点破。他写量子力学的那一章只有十几页，却把"为什么粒子的位置在被观测前是不确定的"讲得让人第一次觉得自己摸到了门。他文笔像散文家，物理对他来说是一种看世界的方式，不是计算工具。如果你以前觉得物理冷冰冰，这本书会改观。

配套：被勾起兴趣后接《现实不似你所见》。

## 《现实不似你所见》

罗韦利 / 2014 / 中等

从德谟克利特的原子论一路讲到圈量子引力，罗韦利的本职研究就在这条线上。

跟《七堂极简物理课》比，这本难度上了一个台阶，因为罗韦利开始认真讲他自己研究的东西 - 圈量子引力理论。书的核心问题是：时间和空间是基本的吗？还是更深层的某种东西涌现出来的？罗韦利的回答是后者，时间在最基础的层面其实不存在，世界由一张"自旋网络"构成。这听起来很玄，但他一步步从古希腊原子论、牛顿的绝对时空、爱因斯坦的相对论、量子场论铺过来，每一步都自然。读完不会让你"懂"圈量子引力，但你会知道现代物理学家在赌什么、为什么赌。

## 《时间简史》

霍金 / 1988 / 中等

二十世纪最畅销的科普书，也是最多人买了不读完的科普书。

霍金的目标是让普通人理解从大爆炸到黑洞的全部宇宙学。书里据说只有一个公式 E=mc²，因为出版商告诉他每多一个公式销量减半。即便这样很多人还是卡在第三章。值得读的原因不是它简单，是霍金在讲一些极端的东西时态度很坦诚 - 黑洞辐射这一段他几乎是在解释自己怎么想出来的，包括最初的错误直觉。后半本关于时间方向、虚时间的讨论现在看有些观点已被超越，但作为一本"科学家亲手解释自己工作"的书，它的位置无人替代。读不下去也别愧疚，挑章节读。

配套：更好读的版本是霍金后写的《果壳中的宇宙》。

## 《自私的基因》

道金斯 / 1976 / 中等

进化论的视角从"生物为了种群繁衍而行动"翻转到"基因为了自身复制利用生物当载体"。

这本是二十世纪最有影响力的科普书之一，影响力不只在生物学。道金斯论证：自然选择的真正单位不是个体，不是物种，而是基因。一只蜜蜂为保护蜂巢而蜇人后死去，看起来是利他，但从基因角度它在保护跟自己几乎一样的同伴基因 - 这就是所谓的亲缘选择。书里关于"互惠利他"的分析借用了博弈论的"重复囚徒困境"，这条思路后来被广泛用在经济学、社会学。最后一章他提出"模因"这个词，指文化的复制单位，互联网时代这个概念已经变成日常词汇了。视角一旦换过来，你看动物行为甚至人类行为的方式都不一样了。

配套：道金斯论证进化本身的书是《盲眼钟表匠》。

## 《盲眼钟表匠》

道金斯 / 1986 / 中等

针对"眼睛这么复杂的器官不可能是随机演化出来的"这种质疑，道金斯写了一整本书做正面回应。

书名来自十八世纪神学家佩利的"钟表匠论证" - 路上捡到一块表，你会推断它有设计者，那么生物比表复杂得多，怎么可能没有设计者？道金斯的回答是：自然选择就是那个设计者，但它"盲眼" - 没有目的、没有远见，只在每代选出活下来的那批。书里有一章用电脑程序演示从随机字符串到"我觉得它像鼬鼠"这句莎士比亚台词需要多少代选择，这个实验的力度比纯讲道理强得多。还有讲眼睛演化的章节，从最简单的感光细胞到完整眼球，每一步中间形态在自然界都能找到。是一本"边读边被说服"的书。

## 《寂静的春天》

卡逊 / 1962 / 入门

杀虫剂 DDT 大规模使用后，鸟群死亡、春天没有鸟叫，卡逊把这件事写出来，引发了现代环保运动。

这本书技术上是科学写作，但实际上改变了历史。卡逊本职是海洋生物学家，她搜集了几百份关于 DDT 和有机氯农药的研究报告，论证这些化学物质如何在食物链里富集、最后毁掉整个生态系统。化工行业对她发动了大规模攻击，骂她是"歇斯底里的女人"，但书的论据扎实，最后美国禁了 DDT，环保署的成立也跟这本书直接相关。读它有两层价值：一是科学论证如何转化为公共行动，二是好的科学写作可以同时严谨和动人 - 开篇"明天的寓言"那一章，描写一个鸟都飞光了的小镇春天，文学性可以进美国二十世纪散文选集。

## 《生命是什么》

薛定谔 / 1944 / 进阶

量子物理学家在二战期间做的几次讲座，问了一个跨学科的问题：生命的物理基础是什么？

这本书只有一百多页，但分量极重。薛定谔从热力学第二定律出发 - 一切系统都倾向无序 - 然后问：那为什么生物能维持高度有序？他的回答是生物从环境"摄取负熵"。书里第二个核心论点是遗传物质必须是某种"非周期性晶体"，能在小到分子的尺度上稳定储存大量信息。这是 1944 年写的，DNA 双螺旋结构 1953 年才被发现。沃森和克里克都明确说过《生命是什么》启发了他们去研究遗传分子。一本物理学家写给生物学的预言书，最后真的被证实，这种事在科学史上也少。难度偏高，但不长，值得啃。

## 《大灭绝时代》

科尔伯特 / 2014 / 中等

地球历史上有过五次大规模物种灭绝，作者论证我们正处在第六次，由人类驱动。

科尔伯特是《纽约客》记者，她做的是一线报道：跟生物学家去巴拿马看金蛙怎么被一种真菌灭种，去澳大利亚大堡礁看珊瑚白化，去冰岛看大海雀的最后一只标本。每一章一个物种，背后是一种灭绝机制 - 气候变化、生境破碎、入侵物种、海洋酸化。她不喊口号，靠一个个案例累积出来的画面已经足够沉重。让这本书跟一般环保书区分开的是地质学视角：她对比了过去五次大灭绝（最著名的是 6500 万年前消灭恐龙的那一次）的速度和规模，把今天物种消失的速率放进去 - 数据本身就是论点。读它会改变你对"自然变化"的尺度感。

配套：底色更乐观一点的环境写作是《沙乡年鉴》。

## 《沙乡年鉴》

利奥波德 / 1949 / 入门

林业学家在威斯康星州买了一块废弃农场，在那里观察一年四季的自然变化，写下来。

这本书是美国环境伦理的奠基作之一。前半部按月份写，一月看雪地里的鹿蹄印，四月听野鹅回来，七月数鸽子，每篇短短几页，文字像散文。但中间一篇《像山一样思考》立刻把书的层次拉高 - 利奥波德回忆自己年轻时打死一只母狼，看着她眼睛里的光熄灭，他突然明白了"山的视角"：狼少了鹿就多，鹿多了草就秃，山就秃了。生态是个整体，单一物种的"有害无害"是人类一厢情愿的判断。书的最后他提出"土地伦理" - 把伦理关怀的对象从人扩展到土壤、水、植物、动物，这个想法在 1949 年是激进的，今天仍然没过时。文字克制、结论深远，是少见的好书。
