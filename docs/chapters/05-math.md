# 五 数学与计算

很多人对数学的最后印象停在高考前夜：一堆要背的公式，一堆要刷的题，一种"做不出来就完蛋"的焦虑。考完之后这些东西像水蒸气一样散掉，剩下的是一个模糊念头：数学和我没关系。

这本指南想换一个角度。数学不是一门考试科目，是一套**抽象工具**。它的用处不是算出某个具体答案，而是让你看清"这两件看起来不一样的事，本质上是同一件事"。素数分布和 RSA 加密、电路里的开关和命题逻辑、递归函数和山中无岁月，这些都是抽象在不同场景里换衣服。

下面这 5 本书没一本要你算积分。它们做的是另一件事：让你看见抽象本身长什么样。前三本入门，从"为什么能搜到我想要的网页"和"二进制怎么变成会动的电脑"这种具体问题切入；中间一本教你怎么解一道你根本不会的题；最后一本是大书，但读它不是为了读完，是为了知道有这么一种思考方式存在。

读完不会让你变成数学家，但会让你下次看到"算法""模型""加密""哥德尔"这些词时，不再觉得是黑话。

## 《数学之美》

吴军 / 2012 / 入门

把搜索引擎、机器翻译、语音识别背后的数学讲清楚，每章一个主题，不超过二十页。

吴军在 Google 做过搜索，回头用通俗中文解释那些看起来很玄的算法到底在做什么。最经典的一章讲贝叶斯：为什么"the"后面接"car"的概率比"接 car"高，怎么用条件概率模型完成机器翻译。还有一章讲信息熵，从香农测一段中文有多少冗余讲起，一路讲到为什么 GB2312 比 UTF-8 更紧凑。这本书的好处是它不藏数学，但也不秀数学，公式只在必要时出现，每个公式都对应一个具体工程问题。读完你会发现，让 Google 工作的不是魔法，是大学一年级就能学的概率论加一点工程直觉。

配套：《浪潮之巅》同作者，讲科技公司兴衰，是这本的姊妹篇。

## 《编码：隐匿在计算机软硬件背后的语言》

查尔斯·佩措尔德 / 1999 / 入门

从两个小孩用手电筒打莫尔斯电码开始，一路推到能跑程序的计算机，全程不跳步。

这本书的结构非常变态：第一章手电筒，第二章盲文，第三章电报，第四章继电器，第五章逻辑门，然后你眼睁睁看着继电器被搭成加法器、加法器被搭成 CPU、CPU 被装上内存。每一步都是上一步的自然延伸，没有"剩下的留给读者"。最神的一章是用继电器手工搭一个 8 位加法器的电路图，作者真的画出每一根线，你跟着读完会有一种"我居然懂了 CPU 是什么"的错觉，但那不是错觉。这是少数能把"抽象层是怎么一层层垒起来的"讲明白的书，读完再看任何编程语言都会觉得清爽。

配套：《计算机程序的构造与解释》（SICP），同样是从底层往上垒，但垒的是软件抽象。

## 《啊哈算法》

啊哈磊 / 2014 / 入门

用"小哼买礼物""坐地铁找最短路线"这种小学生都能听懂的故事，把常见算法讲一遍。

国内算法书一般两种极端：要么是 ACM 选手用的劝退手册，要么是面试速成的八股。这本书走第三条路，把排序、栈、队列、图、最短路、深度搜索全部包装成连环漫画式的小故事。讲冒泡排序时它真的画一群小人在那儿冒泡；讲 Dijkstra 时它假装你在画地铁线路图。代码量不大，每段都能在十分钟内自己敲出来跑通。它不会让你拿去参加竞赛，但能让你第一次"感觉到"算法是个具体的、可以在脑子里运转的东西，而不是一堆要背的伪代码。读完再看《算法导论》，至少知道每章在解决什么问题。

配套：《算法图解》（Aditya Bhargava），更短，画风更像绘本，可以二选一。

## 《怎样解题》

乔治·波利亚 / 1945 / 中等

不是教你解某道题，是教你"面对一道完全不会的题，下一步该想什么"。

波利亚是数学家，但这本书写给中学老师。他把"解题"拆成四个动作：理解题意、拟定计划、执行计划、回顾。每一步背后有一串提示词，比如"你以前见过类似的题吗""能不能换一种说法""能不能先解一个更简单的特例"。听起来像废话，但实际操作时极度有用。书里有一个例子让我记到现在：求一个不规则四面体的体积，作者不直接套公式，而是问"如果它是个长方体的一部分会怎样"，然后把它补成长方体减去三个角。这个动作叫**化归**，是数学里最朴素也最强的武器之一。这本书的价值不在数学本身，在于它把"卡住时怎么办"这件原本只能靠天赋的事，变成了可以练的流程。

配套：《数学：它的内容、方法和意义》（亚历山大洛夫等），三大卷，想看苏联学派怎么俯瞰整个数学版图就读它。

## 《哥德尔、艾舍尔、巴赫》

侯世达 / 1979 / 进阶

用一个数学家、一个版画家、一个作曲家的作品，绕着同一个主题转：什么是"自我指涉"，以及它和心智的关系。

简称 GEB，普利策奖。它不是数学书也不是计算机书也不是艺术书，但又全是。书的主线是哥德尔不完备定理：一个足够强的形式系统里，必然存在一句话说"这句话在本系统内不可证"，因此系统要么不完备要么不一致。侯世达不直接证给你看，他让乌龟和阿基里斯演对话，让艾舍尔的画里手画手，让巴赫的卡农自己变奏自己，然后说，这些都是同一种结构。最妙的是关于 MU 谜题那一章：他设计一套字符串改写规则，让你试图从 MI 推出 MU，你怎么试都试不出来，因为你站在系统内；只有跳到系统外数 I 的个数模 3，才看得见障碍。这本书厚到吓人，不必读完，挑前三百页 +"对话"部分就够，能读到的部分会永久改变你对"层次""规则""自我"的感觉。

配套：《集异璧之大成》是中译本名字，有删节；英文原版插图更清楚。
