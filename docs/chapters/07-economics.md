# 七 经济金融

经济学不是教你赚钱的学问，是教你看见社会运转的隐藏机制。

大部分人对经济学有两个误解：一是觉得它跟自己无关，那是西装革履的人在电视里讨论 GDP；二是觉得它就是理财，读了能教你怎么炒股、怎么财务自由。两个都错。经济学真正在做的事，是回答一些非常具体的问题：为什么这家咖啡馆开在这里、为什么牛奶比可乐贵、为什么穷人借钱的利率比富人高、为什么有的国家从殖民地起步走到了发达、有的没有。这些问题背后是一整套关于激励、价格、信息、制度的逻辑。读懂了，你看新闻、看政策、看自己的工资单都会多一层视角。

下面 10 本，3 本经济学理论框架，3 本入门级的经济学思维训练，2 本发展经济学解释为什么有的地方穷，2 本投资和不确定性。不是按"重要性"排，是按你能不能读得下去排。

## 《经济学原理》

曼昆 / 1998 / 入门

全世界用得最广的经济学教材，从十大原理讲到宏观货币政策。

如果你想系统地理解一次经济学，这本是最不痛苦的入口。曼昆的写法不像教科书，更像一个聪明朋友给你解释为什么超市要打折、为什么央行加息会影响你的房贷。他强调的"十大原理"里有几条特别值得记住：人们面临权衡取舍、某种东西的成本是为了得到它所放弃的东西、理性人考虑边际量。这三条几乎能解释一半的日常决策。书很厚，分微观宏观两册，不用一口气读完，当工具书放着，看新闻看到 CPI、通胀、外汇就翻一翻对应章节。

配套：如果觉得太厚，可以从《牛奶可乐经济学》入手。

## 《牛奶可乐经济学》

罗伯特·弗兰克 / 2007 / 入门

用一百多个生活小问题（牛奶盒为什么是方的、可乐瓶为什么是圆的）讲经济学直觉。

弗兰克在康奈尔教经济学，他给学生布置的作业不是写论文，是观察身边一个奇怪现象然后用经济学解释。这本书就是那些作业的精华。问题都很小：为什么 24 小时营业的便利店门上还装锁、为什么女装的纽扣在左边男装在右边、为什么飞机上的婴儿不用买票。但每一个的答案都涉及一个真正的经济学概念，成本曲线、信息不对称、网络效应。读完你会发现一件事：经济学家看世界的方式和普通人不一样的地方，不是知道更多，是习惯性地问"为什么是这样而不是那样"。

## 《魔鬼经济学》

列维特 / 都伯纳 / 2005 / 入门

用经济学方法研究一些奇怪的问题：相扑选手作弊、毒贩为什么和妈妈住、堕胎合法化怎么影响了犯罪率。

这本书让你看明白一个误区：经济学不等于研究钱。它是一套分析激励的工具，可以用在任何有人做选择的场合。列维特最擅长的是从大量数据里找出反直觉的因果关系。书里最经典的案例是论证 1990 年代美国犯罪率下降的真正原因不是警力增加，而是 1973 年堕胎合法化让那一批"非意愿出生"的孩子没有出生。这个结论引发巨大争议，但论证过程是教科书级的。读这本书最大的收获是学会问：这件事真的是它看起来那个原因吗？

配套：续作《超爆魔鬼经济学》也好看。

## 《国富论》导读版

亚当·斯密 / 1776（导读版近年皆有）/ 中等

现代经济学的奠基之作，提出了"看不见的手"和分工理论。

直接读 1776 年的原版会很痛苦，斯密的句子又长又绕，举的例子也都是别针工厂和苏格兰呢绒商人。但导读版（中信、商务都出过）保留了核心思想：财富不来自黄金白银的积累，来自分工和交换；每个人追求自利，市场会通过价格自动协调出整体福利。这个想法在 1776 年是革命性的，在今天仍然是大部分市场经济政策的底层逻辑。读它不是为了学操作，是为了理解你每天用钱买东西这个动作背后，是一套花了两百多年才被完整阐述的思想。

## 《通往奴役之路》

哈耶克 / 1944 / 中等

二战期间写的一本警告：从计划经济走向极权只有一步之遥。

哈耶克想回答的问题是，为什么德国从一个文明国家变成了纳粹。他的答案是：当国家承担起规划经济、分配资源的责任，权力会自动集中，而集中的权力一定会扩张到生活的所有领域。书里最有力的不是抽象论证，是他对"善意的计划者"的解剖：那些真心想让社会更公平的人，恰恰会成为通往不自由的开路者。这本书在冷战年代被当作反共宣传，今天读会发现它真正在讨论的是一个更根本的问题：当效率和自由冲突时，经济学家应该站在哪一边。读完不一定同意他，但你的政治经济学词汇会丰富一倍。

## 《贫穷的本质》

班纳吉 / 迪弗洛 / 2011 / 中等

两位 2019 年诺奖得主，用十几年的随机对照实验研究：穷人为什么穷。

这本书最颠覆的地方在于，它不接受任何一种关于贫穷的简单解释。不是穷人懒、不是制度问题、不是教育不够，也不是单纯的钱不够。作者把"穷"拆成几十个具体场景：穷人为什么不存钱、为什么不打疫苗、为什么宁可买电视也不买蚊帐。每一个问题用田野实验得出答案，而答案往往出人意料。比如发现穷人不是不想存钱，是没有合适的存钱工具；不是不知道蚊帐有用，是免费发的反而比卖的使用率高。读完你对"扶贫"两个字的理解会完全不同，会明白为什么大量的善意援助没用，少数几个机制设计精巧的项目却改变了一代人。

## 《国家为什么会失败》

阿西莫格鲁 / 罗宾逊 / 2012 / 中等

为什么有的国家富有、有的贫穷？答案不是地理、文化、宗教，是制度。

作者用一个对比开篇：美墨边境上有一座城叫诺加莱斯，被一道墙分成两半。墙这边是美国亚利桑那州的诺加莱斯，人均收入三万美元；墙那边是墨西哥的诺加莱斯，一万美元。同样的人种、文化、气候、地理，差别只在制度。书的核心论点是：能让一个国家长期繁荣的，是"包容性制度"，让普通人有产权、有上升通道、能参与政治；与之相对的"汲取性制度"短期可能高速增长，但长期一定会停滞，因为它本质上是少数人对多数人的剥夺。这本书会改变你看待历史和当下的角度，殖民、革命、改革，背后都是同一个变量在变化。

配套：作者新书《狭窄的走廊》讨论自由和国家权力的平衡，可以接着读。

## 《聪明的投资者》

本杰明·格雷厄姆 / 1949 / 中等

价值投资学派的源头，巴菲特的老师写的书。

不要被书名误导，这不是一本教你选股票的操作手册。它真正讨论的是一个心理学问题：在一个每天都有人告诉你"要赚大钱"的市场里，如何不被情绪带走。格雷厄姆提出了两个一直影响后人的概念。一是"市场先生"，把市场拟人化成一个躁狂抑郁的合伙人，今天报高价明天报低价，你的任务不是猜他下一步报什么，是判断标的真实价值，然后等他报错价。二是"安全边际"，永远以低于内在价值的价格买入，给自己留出犯错的空间。读这本书让你看明白一个误区：投资的对手不是市场，是你自己的恐惧和贪婪。

## 《穷查理宝典》

查理·芒格 / 2005 / 入门

巴菲特的合伙人芒格的演讲合集，讲的是怎么思考、怎么避免愚蠢。

芒格不是经济学家，是律师出身的投资人，但他对世界的理解方式比大部分经济学家都通透。这本书的核心概念是"多元思维模型"：要理解一件事，得同时调用心理学、物理学、生物学、经济学的几十个模型。他列了大概一百个常见的认知偏误，从"嫉妒-敌意倾向"到"过度乐观倾向"，每一个都举了商业和生活的例子。读这本书让你看明白一个误区：聪明人犯错不是因为不够聪明，是因为只用一种思维方式看所有问题。芒格的建议是，每天努力让自己比昨天稍微少一点蠢。

## 《黑天鹅》

塔勒布 / 2007 / 中等

讨论那些罕见、影响巨大、事后才被合理化的事件，比如 911、2008 金融危机。

塔勒布的核心观点是：人类的大脑天生不擅长理解极端事件。我们用正态分布去想问题，用历史数据去预测未来，但真正改变世界的从来不是平均值，是尾部那些谁也没预料到的极端。书里区分了两种世界，"平均斯坦"和"极端斯坦"。在前者里身高、体重这种东西都符合正态分布，单个样本不会颠覆整体；在后者里财富、市场、影响力按幂律分布，一个比尔·盖茨能拉高一万人的平均收入。问题是大部分人把第二种世界当第一种来理解，于是反复在金融危机、政治黑天鹅面前措手不及。读完这本书你不会变得更会预测，但会对"专家信誓旦旦的预测"产生健康的怀疑。

配套：续作《反脆弱》讲怎么在不可预测的世界里构建受益于波动的系统，更进阶。
