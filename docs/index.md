# 阅读指南：100 本书

> 博尔赫斯曾说：“我心里一直都在暗暗设想，天堂应该是图书馆的模样。”

人这一生有限，不可能把每个领域的书都系统读完。比起读得多，更要紧的是尽早遇上那些值得反复翻开的书：它们能给出一套可靠的知识坐标、一种清楚的分析框架，或者推开一扇此前没注意到的窗子，让人换一种眼光打量世界。

这份《阅读指南》跨十二个领域，挑出一百部经得起慢读的作品。它不做“人类最伟大百部经典”之类的排座次，也没打算拿一百本书把哪个学科封死，更像一张帮人找路的入口地图。里头有直接开创传统的原典，有帮人搭起学科骨架的通识导读，也有几部曾在历史上掀起大浪、但今天读来需要结合新证据加以修正的旧作。选书时主要看四条：问题抓得深不深、文字立得住立不住、在学科里够不够有代表性，以及普通读者能不能读进去。

## 📖 如何使用这份书单

每章选入的书大致分三类：

1. **原典**：直接把人带进一个思想传统或文学世界；
2. **经典导读**：帮初学者先搭起某个领域的整体坐标；
3. **历史性作品**：曾深刻改变一个学科或公共讨论，但其中部分结论需要放回当时的语境里审视。

每本书的导读围绕四件事展开：它在谈什么问题，为什么值得一读，它在思想或形式上打开了什么新路，今天读它时又要留心哪些局限。

书单不评星级，也不必从头到尾按顺序读。好的阅读往往始于一个真正绊住你的问题：先挑最让你好奇的那一本翻开，再顺着它引出的线索一圈圈往外读。
