# 阅读指南：100 本书

12 个领域，100 本书。每本写一段推荐，告诉你这本书是讲什么的、为什么值得读、适合什么时候读。

不是"必读经典"那种正经书单。挑书的标准是：读完之后世界观变了一点、看问题多了一个角度、或者文字写得真好。

## 每本书的格式

每本书一段：
- 书名 / 作者 / 出版年 / 难度（入门 / 中等 / 进阶）
- 一句话讲这本书在写什么
- 一段为什么推荐
- 配套阅读（如果有同主题更进阶或更入门的）

不写"五星推荐"那种打分。书没有客观好坏，只有合不合你这阶段。
